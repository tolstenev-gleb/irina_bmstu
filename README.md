1. Целочисленный массив содержит максимум 15
   элементов. Подсчитать число элементов
   массива, которые являются степенями двойки.
   Полученное число вывести на экран.
2. Целочисленный массив содержит максимум 15
   элементов. Найти индекс максимального
   элемента массива, среди тех элементов,
   произведение цифр которых отлично от нуля.
   Значение индекса вывести на экран.
3. Целочисленный массив содержит максимум 15
   элементов. Если все элементы массива
   являются числами Фибоначчи, вывести «YES», в
   противном случае «NO».
4. Реализуйте функцию циклического сдвига
   элементов массива вправо на один элемент. С
   помощью реализованной функции поместите
   максимальный элемент массива на последнее
   место в массиве. Если максимальных
   элементов несколько, на последнем месте
   должен оказаться первый.
   Вывести на экран элементы измененного
   массива, разделив их пробелами.
5. Реализуйте функцию обращения (реверса)
   массива. Используйте указанную функцию для
   циклического сдвига массива на К позиций
   влево, используя следующий алгоритм
   реверс первой части [0, К — 1]
   реверс второй части [К, n — 1]
   реверс всего массива
6. Удалите из массива все элементы с четной
   суммой цифр. дополнительные массивы
   использовать нельзя.
   Вывести на экран элементы измененного
   массива, разделив их пробелами. Если массив
   пустой, вывести «ЕМРТУ».
7. В массиве не более 10 чисел.
   После каждого элемента массива, являющегося
   полным квадратом, вставить число из которого
   этот полный квадрат получен. для определения
   факта, что число является полным квадратом,
   использовать целочисленный алгоритм (нельзя
   использовать функции pow и sqrt).
8. Целочисленный массив содержит максимум 1 5
   элементов. Найти количество различных
   элементов в массиве. Значение количества
   вывести на экран.
